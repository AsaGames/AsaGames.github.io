# Asa's Games

The home page for Asa's browser games: https://asagames.github.io/

## Adding a new game

1. Put the game in its own repository in the AsaGames organization and turn on GitHub Pages for it (Settings → Pages → deploy from the `main` branch). It will be at `https://asagames.github.io/<Repo-Name>/`.
2. Add a 1280×720 screenshot to `images/`.
3. In `index.html`, copy the Titanic Game `<article class="card">` block, then change the picture, title, description, chips and links. Remove `featured` from the class to make it a normal-sized card, or move it to the newest game.
